## 三、值得读的页 ↔ 三层漏斗 ↔ 里程碑

### L1 系统层（配 M2）

| 页 | 一句话 | 怎么读 |
|---|---|---|
| `design/arch_overview.md` §V1 Process Architecture | API server / engine core / GPU worker / DP coordinator 四个进程 + 进程数公式，IPC 走 ZMQ | 只读这一节，前面 LLMEngine 段跳过 |
| `serving/online_serving/README.md` | 所有入口端点总表（OpenAI / Anthropic / pooling / speech / custom…） | 扫标题，知道请求从哪个门进来 |

### L2 模块层（配 M1）

| 页 | 一句话 | 里程碑 |
|---|---|---|
| `usage/v1_guide.md` | V1 的模块边界；unified scheduler 用 `{request_id: num_tokens}` 做预算 | M1 |
| `design/metrics.md` §Metrics Collection / Scheduler Stats / Engine Core Events | **EngineCore = 内循环（性能关键）、AsyncLLM = 外循环（承担开销）**的分工原则；`QUEUED`/`SCHEDULED`/`PREEMPTED`/`NEW_TOKENS` 四事件 | M1 |
| `configuration/optimization.md` §Preemption / §Chunked Prefill / §Attention Backend Selection / §CPU Resources | V1 默认抢占 = `RECOMPUTE`（不是 SWAP）；chunked prefill 默认开、decode 优先、预算 = `max_num_batched_tokens`；还给了一条真实 preempt 日志行 | M1、M7 |
| `design/hybrid_kv_cache_manager.md` | hybrid 模型（sw+full / mamba+full）的 KV 分配与 page size 统一算法 | M4、M7 |
| `design/prefix_caching.md` | block hash 的组成（parent hash + block tokens + extra hashes）；只缓存满块；v0.11 起默认 sha256 | M7 |
| `design/attention_backends.md` | 后端优先级 / 特性矩阵（脚本自动生成）+ 选择行为 | M6 |
| `features/disagg_prefill.md`、`features/sleep_mode.md`、`features/batch_invariance.md` | 少数"写了内部取舍"的特性页（KV 传输契约 / 权重与 KV 两级释放 / 确定性与 CUDA graph 的冲突） | M7 及以后 |

> `design/metrics.md` 的价值被标题低估了：它是官方的「**指标名 → 模块**」对照表，正好对上 M1 的验收标准（给一条日志行，说出是哪个模块打的）。

### L3 函数层（配 M3–M6）

| 页 | 一句话 | 里程碑 |
|---|---|---|
| `design/model_runner_v2.md` | MRV2 重设计：persistent batch 与输入张量解耦、async-first、去 barrier | M5（先知道 MRV2 尚未 feature-complete，你仓库里跑的是 V1 runner） |
| `design/cuda_graphs.md` | `CUDAGraphMode` 四档（NONE / PIECEWISE / FULL / FULL_DECODE_ONLY）的取舍 | M5 |
| `design/torch_compile.md`、`fusions.md`、`vllm_ir.md`、`optimization_levels.md` | 编译、融合 pass、IR 与 lowering | M5/M6 收尾，有余力再进 |
| `contributing/profiling.md` | torch / Proton / Nsight / cProfile + start/stop_profile | **唯一官方给的「L2 → L3 观测」入口**，M3 起就用 |
| 本地 `docs/v0.30主干函数阅读清单.md` | 行号索引 | M3–M6 跳函数时用 |

### 整块跳过的部分

User Guide 里约 90% 是操作向：量化工具链（awq/gptq/bnb/gguf/torchao…）、各种连接器、多模态、tool calling、structured outputs、K8s/Docker/Nginx、第三方框架与集成。`configuration/engine_args.md`、`env_vars.md` 当字典查，不要通读。

## 六、在线读法备忘

- Design 文档的 URL 是 `/design/<name>/`（**带尾斜杠**），站点**没有** `/design/` 索引页；导航树在 Developer Guide → Design Documents。
- 该站没有 `llms.txt` / `llms-full.txt`（均 404），无法一次拉全站纯文本；但任意 404 页会渲染完整左侧导航树，可用来枚举页面。
- 直接 curl 会被 Cloudflare 拦（429 "Just a moment..."）；用 `read_page` 走 Firecrawl 可正常读。
