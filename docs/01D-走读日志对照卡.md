## 两套日志怎么配合走读

1. **serve 日志**（`logs/vllm-qwen35-08b-*.log`）：按 #1→#16 顺序过。重点 #2/#4 双进程前缀、#1 路由注册 → docs/01 Q1 的日志侧答案。
2. **离线日志**（`test_vllms/test_qwen3.5_0.8b.log`）：内核环节更干净 —— #7 chunked prefill、#12 KV 数字、#13 显存账。
3. **动手验证**（可选）：

## 走读 3 个观察点

1. **Q1「每跳传什么」**：日志看不到对象，但进程前缀切换（APIServer → EngineCore）就是 core_client 边界 —— 传 `EngineCoreRequest`。
2. **Q4 KV layout**：#11 的 544 / 784 就是 `kv_cache_layout.py` 算的页对齐结果，混合注意力专属。
3. **Q3 preemption**：冒烟日志 `Running: 0 reqs`，逼不出来。要高并发（W2 27B 限参）。V1 主路径 = recompute，无 CPU swap。
